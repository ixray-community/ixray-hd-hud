## Overview

The main goal of the add-on is to modernize the original interface while preserving its initial concept and aesthetic. All textures have been completely redrawn by hand, without using old assets or artificial intelligence technology

## Remarks

> [!WARNING]
>
> Supported only on __IX-Ray Platform__!

## Requirements

Installation:

1. Install original Stalker Call of Pripyat 1.6.02
2. Install current version of IX-Ray (minimum 1.3.1)
3. Extract addon archive into the game folder
4. Start the game and play

Link to the current __IX-Ray__ [release](https://github.com/ixray-team/ixray-1.6-stcop/releases/latest)
